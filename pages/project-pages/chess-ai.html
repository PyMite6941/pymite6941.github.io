Chess AI

Minimax engine expanding toward a self-play DQN

Description


What it is: A chess engine built in Python. The classical search layer uses minimax with alpha-beta pruning to cut the game tree — the same approach used in the Connect 4 Bot, scaled up to chess's larger branching factor.

Where it's going: Expanding toward a Deep Q-Network trained entirely via self-play, building on the Q-learning architecture from Pixel-APEX. The goal is an engine that improves through experience rather than hand-tuned evaluation functions.

Why chess: Chess is the canonical benchmark for game AI — beating minimax with learned evaluation is a concrete, measurable milestone. It also directly feeds into NOAI competition prep.

Dev Notes

Tech Stack

Python, PyTorch for the DQN layer, python-chess for move generation and board representation.

From Connect 4 to Chess

Connect 4 Bot proved the minimax + DFS approach. Chess has a branching factor ~35 vs Connect 4's ~7 — alpha-beta pruning is essential, not optional.

DQN Goal

Replace the static evaluation function with a network trained via self-play. Architecture mirrors Pixel-APEX's Q-arbiter but applied to a continuous-improvement loop.
