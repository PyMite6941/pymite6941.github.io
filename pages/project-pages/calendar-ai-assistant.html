Description


What it does: Connects to your Google Calendar and Gmail via OAuth and lets you manage your schedule through natural language. Add events, query your week, turn emails into todos, or generate an optimized daily time-block plan — all from a single prompt. A 4-agent CrewAI pipeline (intent analyzer → data retriever → processor → verifier) handles every request end-to-end. Available as a Streamlit Web UI and a full CLI.

How it was built: Python core. CrewAI orchestrates the agent pipeline. Google Calendar API and Gmail API provide the data layer, authenticated through OAuth with automatic token caching and refresh. Streamlit powers the Web UI. A dedicated planner agent converts a freeform task list into an optimized, context-switch-minimizing schedule. Config and secrets live in TOML files; event and todo state persists in JSON.

Architecture: backend/agents/ holds all four agent and task definitions. backend/tools/ provides the calendar, todo, config, and scraping utilities each agent calls. frontend/ splits into cli/cli.py and streamlit/Page.py, both backed by the same backend/ layer so features stay in sync. run.py is the single entry point.

Dev Notes

Problem Solved

Calendar apps show you data but don't reason about it. This project lets you talk to your schedule the same way you'd ask a human assistant — and have it actually take action, not just display information.

Technical Highlights

The 4-agent pipeline keeps each concern isolated: the intent agent never touches the API, the data agent never interprets intent. The verifier catches errors before they reach the user — a pattern worth reusing across agent projects.

What's Next

Recurring event support, conflict detection that reasons about travel time, and a push notification layer so the assistant can proactively remind you about upcoming schedule gaps or overloaded days.
