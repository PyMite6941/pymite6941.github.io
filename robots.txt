# robots.txt — pymite6941.is-a.dev
#
# Two rules govern this file:
#
# 1. Search engines stay allowed on every page that carries personal detail.
#    The pages that should not show up in results control that themselves with
#    a meta robots tag — college-tracker.html is "noindex, nofollow" and
#    college-essay.html is "nosnippet, noarchive, max-snippet:0". A crawler has
#    to fetch a page to read that tag, so disallowing a search engine here
#    would break the very thing it is meant to enforce. Nothing below blocks a
#    search engine from one of those pages.
#
# 2. AI training crawlers and commercial scrapers are blocked from every file
#    that carries personal information: the resume (email, GPA, SAT scores,
#    school, citizenship), the academic record, the college tracker, the
#    scholarship plans, the contact page, and the whole documents folder. The
#    rest of the site stays open to them so the project work still gets picked
#    up.
#
# Two JavaScript files are named below, which is easy to miss: a page's meta
# robots tag protects the page, not the data file it loads. Both of these are
# separate fetchable URLs carrying the same personal detail as the pages —
# college-tracker-data.js holds the name, school, GPA, SAT and the full
# school-by-school application strategy, and audience-router.js holds the
# academic snapshot shown in the homepage modal.
#
# robots.txt is voluntary, so it is not the only control. The resume carries
# "noindex, noarchive, nosnippet"; academics.html carries "nosnippet,
# noarchive, max-snippet:0"; and every published email address is HTML
# entity-encoded so a source-scraping harvester finds no address to match.

# ---------------------------------------------------------------------------
