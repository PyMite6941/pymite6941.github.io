About Me

Matt Gresham


I'm a self-taught developer building toward a career at the intersection of AI/ML, cybersecurity, and software engineering. My stack is Python for logic-heavy work and Go for performance-critical tools, with React when the project needs a frontend.

I started programming to scratch my own itch — the Finance Kit began as a school submission and grew into a full-stack deployed app. That pattern repeats across my work: I build something I'd actually use, then push it until it's production-ready.

Current focus: cybersecurity tooling, algorithm design for the NOAI competition, machine learning fundamentals, and embedded systems via the PhysTech hardware watch project.
