Description


Context: Built as a submission to the International AI Agents Hackathon 2026. The challenge was to design autonomous, multi-step AI agent systems — programs that can plan, use tools, and complete tasks without constant human input.

What it does: A multi-agent system that automates data processing tasks. Agents coordinate to ingest, analyse, and output structured results — the core logic lives in backend/bots.py, with a frontend deployed on Vercel.

How it was built: Python for the agent backend, drawing on prior multi-agent architecture experience from Pixel-APEX and Study Assistant. Deployed with a web frontend on Vercel.

Status: Submitted to the International AI Agents Hackathon 2026. See the hackathon page for competition details.

Dev Notes

Problem Solved

Manual data processing is repetitive and error-prone. Autonomous agents can ingest, clean, and analyse data end-to-end without needing step-by-step human direction.

Tech Stack

Python for the agent backend (backend/bots.py), with a web frontend deployed on Vercel. Multi-agent coordination draws on architecture patterns from prior AI projects.

What I Learned

Designing agents that hand off tasks to each other cleanly — the orchestrator pattern, how to structure subtask routing, and keeping agent responsibilities narrow enough to be reliable.
