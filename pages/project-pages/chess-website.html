Description


Context: I play chess regularly and wanted a project that would push me to learn React properly — not with a tutorial app, but with something I'd actually use.

Challenges: Wiring up react-chessboard-ui with correct state management for legal move validation, and setting up React Router so the home page and play page are cleanly separated. Deploying a Vite app to Vercel required configuring the build output correctly.

Result: A deployed chess app where you can play a full game against yourself or a friend. Built with React + Vite, routed with React Router, and live on Vercel. The project established my React fundamentals for every frontend project since.

How It's Built


React Component Tree ══════════════════════ main.jsx └── <BrowserRouter> └── <App /> └── <Routes> ├── "/" → <Home /> │ hero + nav links └── "/play" → <Play /> └── <Chessboard /> (react-chessboard-ui) │ │ onPieceDrop(src, tgt) │ validate → update FEN → re-render ▼ game state (FEN string in useState) React Router v6 separates Home and Play. All game state lives in Play and flows down to the board.

FEN String — What It Encodes ══════════════════════════════ rnbqkbnr/pp1ppppp/8/2p5/4P3/8/PPPP1PPP/RNBQKBNR w KQkq c6 0 2 │ │ │ │ │ │ │ piece placement (rank 8 → rank 1) │ │ │ │ └─ full move │ uppercase=White lowercase=Black │ │ │ └─── half move clock │ digits=empty squares │ │ └─────── en passant target │ │ └──────────── castling rights │ └────────────── active colour (w/b) On every piece drop: ──────────────────── old FEN + move → validate legality → new FEN → setState Stale FEN bug: async setState meant onPieceDrop read the old FEN, allowed illegal moves through. Fix: read FEN from a ref, not from state. FEN is the single source of truth — no separate piece array, no board matrix.

Dev Notes

Problems Solved

Tutorial React projects teach very little that transfers to real work. I needed a project with genuine state management, routing, and deployment complexity — something I'd actually use. A playable chess app fit all three.

Errors & Fixes

react-chessboard-ui required managing the full FEN string on every move to keep legal validation working — a stale FEN bug let illegal moves through until I traced the state update order. Vite's build output directory also needed explicit config before Vercel could find the dist folder.

What I Learned

React hooks state management, React Router v6 setup, and Vite + Vercel deployment. Also learned how to read library source code when the docs are thin — the react-chessboard-ui internals explained more than the README did.
