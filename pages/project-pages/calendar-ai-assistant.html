Description


What it does: Connects to your Google Calendar and Gmail through OAuth 2.0 and lets you manage your schedule entirely in plain English. Add events, query your week, turn emails into todos, and generate an optimized time-block plan from a task list — all from a single chat prompt. A 4-agent CrewAI pipeline handles every request: Intent Analyzer → Schedule Data Retriever → Schedule Processor → Response Verifier. Available as both a Streamlit Web UI (with a full calendar grid, todo list, settings, and a built-in portfolio page) and a rich CLI.

AI Providers: Supports 5 providers switchable from the Settings page — OpenAI Groq Gemini Mistral Ollama — so it runs fully offline with Ollama or on free cloud tiers. Provider and model are stored in secrets.toml and never hardcoded.

Google Integration: Reads and writes Google Calendar v3 and reads Gmail v1 via OAuth 2.0. The token flow is handled by backend/auth/add_google_oauth.py, which caches credentials with pickle and refreshes them automatically. A "Connect Google Account" button lives in the Settings page; once connected the Portfolio page shows live account status and upcoming events pulled directly from the API.

How it was built: Python core. CrewAI 1.1 orchestrates the agent pipeline. streamlit-calendar renders the month/week/day grid. Config in TOML; events and todos persisted as JSON; OAuth tokens in pickle. A run.py launcher with questionary lets you choose CLI or Streamlit on startup.

Streamlit App Pages


Calendar

Full streamlit-calendar grid with month, week, and day views. Events pulled from Google Calendar via the data retriever agent and rendered live. View preference saved in configs.toml.

AI Chat (Sidebar)

Persistent chat sidebar across all pages. Ask anything about your calendar — the pipeline runs, returns a verified response, and any calendar actions (add event, add todo) are applied immediately.

Todo List

Add and delete tasks with titles and descriptions. Stored in todos.json. The AI can generate todos from chat prompts or turn Gmail threads into task items.

Settings

Choose AI provider (OpenAI / Groq / Gemini / Mistral / Ollama), set model name, enter API key, set calendar view default. Google OAuth connect / disconnect button. One-click cache clear.

Portfolio (built-in)

The app ships with its own portfolio page — shows live metrics (5 providers, 2 interfaces, 4-agent pipeline), full feature list, architecture diagram, tech stack, and live Google account status with upcoming events.

Description

Reads and renders README.md directly inside the Streamlit app so the project description stays in sync with the repo automatically.

Dev Notes

Problem Solved

Calendar apps show data but don't reason about it. This lets you talk to your schedule like a human assistant — and have it actually act: create events, file todos, read your Gmail, build a time-block plan from a task list.

Hardest Part

Google OAuth across two developers and two runtime modes (CLI vs. Streamlit). Token refresh had to be airtight — a stale token mid- pipeline breaks the whole crew. Also keeping CLI and Streamlit page feature parity as the project grew.

What I'd Do Differently

Abstract all Google API calls into a single data layer from day one instead of letting both interfaces call the API directly. Would have prevented several sync bugs and made adding features much cleaner.
